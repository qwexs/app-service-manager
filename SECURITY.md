# Security

This project is experimental and is not a security sandbox. Treat manifests, executables, health commands and Compose files as trusted code. Keep credentials and runtime data outside the repository. Release hashes from the same storage as artifacts do not authenticate their publisher.

Please report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting if available. Do not publish credentials or exploit details in a public issue. If private reporting is unavailable, contact the owner through a private channel before sharing sensitive details. No response-time or support guarantee is currently provided.
